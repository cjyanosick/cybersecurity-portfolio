About

Cybersecurity with a business and leadership mindset.

I am a cybersecurity professional building hands-on experience across networking, system security, cryptography, security operations, secure software development, cyber risk, and governance.

My primary interest is the point where technical security becomes an organizational decision. Finding the vulnerability matters, but so does understanding its severity, determining the business impact, explaining the risk clearly, and deciding what should happen next.

Featured Work

Building with privacy and security in mind.

ASTI — A Local-First Personal AI Assistant
IN DEVELOPMENT

A personal AI assistant built around a simple principle: private by architecture, local by default, cloud by choice. It runs entirely on local hardware through Ollama, with no cloud dependency required — and every architectural decision is made with future encryption and user control in mind, not bolted on after the fact.

01 / FOUNDATION

Local-first by default

Runs on local models through Ollama, keeping data on the user's own machine instead of a cloud-managed profile.

02 / PRIVACY ENGINEERING

Designed for encryption before it's needed

Migrating memory access onto a dedicated storage abstraction layer now, so encryption at rest and OS-level key management can be added later without a rewrite.

03 / ROADMAP

Expanding deliberately

New memory categories and features stay paused until the secure storage foundation is solid — capability follows security, not the other way around.
